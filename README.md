# Thimmo WebForge — Website Storefront

This is the actual Thimmo WebForge sales website: customers browse ready-made websites, filter by category, view prices, and submit an order request.

Files:
- index.html — storefront
- styles.css — complete responsive design
- script.js — product catalogue, filters, order forms and local demo storage

Open index.html to run it.

IMPORTANT BEFORE PUBLIC LAUNCH:
1. Replace hello@webforge.example with your real email.
2. Replace the demo order/contact form handlers in script.js with a real backend, email service, WhatsApp link, CRM or payment provider.
3. Replace product prices/content with your real offers.
4. Add real screenshots/images of the websites you sell.
5. Add your own terms, refund policy and privacy notice.
6. For actual payments, use a legitimate payment provider rather than collecting card details in this static site.

The storefront is intentionally static and dependency-light so it is easy to host and customize.
